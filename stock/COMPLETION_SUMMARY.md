## 🚀 실행 방법

### 1️⃣ 환경 설정

```bash
# .env 파일 생성
cp .env.template .env

# .env 파일 편집
nano .env

# 다음 정보 입력:
KIS_APP_KEY=발급받은_APP_KEY
KIS_APP_SECRET=발급받은_APP_SECRET
KIS_ACCOUNT_NO=계좌번호-01
KIS_BASE_URL=https://openapi.koreainvestment.com:9943
```

### 2️⃣ API 연결 테스트

```bash
# 기본 연결 테스트
cargo run --bin kis-test -p stock-recommender

# 시세 조회 테스트
cargo run --bin kis-price-test -p stock-recommender
```

### 3️⃣ 자동매매 실행

```bash
# DRY-RUN 모드 (안전, 시뮬레이션만)
cargo run --bin kis-auto-trading -p stock-recommender

# 실전 거래 모드 (주의!)
cargo run --bin kis-auto-trading -p stock-recommender -- --real
```

## 🎯 핵심 기능

### 1. 실시간 시세 조회
```rust
let price = api.get_stock_price("005930").await?;
println!("삼성전자 현재가: {}원", price.current_price);
```

### 2. 자동 매수
```rust
// 조건: 현금 비율 > 40% && 미보유 종목
if cash_ratio > 40.0 && !positions.contains(stock_code) {
    execute_buy(stock_code, price).await?;
}
```

### 3. 자동 매도
```rust
// 조건 1: 목표 수익률 달성
if profit_rate >= 3.0% {
    execute_sell(stock_code, quantity, price).await?;
}

// 조건 2: 손절매
if profit_rate <= -2.0% {
    execute_sell(stock_code, quantity, price).await?;
}
```

### 1. DRY-RUN 모드 (기본)
- 실제 주문 없음

- 최소 30% 현금 보유
- 과도한 집중 투자 방지

### 3. 손실 제한
- 자동 손절매: -2%
- 포지션 가치 실시간 추적
- 총 자산 모니터링

## ⚠️  중요 주의사항

### API 사용 제한
- 토큰 발급: **1분당 1회**
- 시세 조회: 초당 제한 있음
- 주문: 적절한 간격 유지

### 실전 거래 시
1. **소액으로 시작** (10만원~50만원)
2. **DRY-RUN으로 충분히 테스트**
3. **로그 실시간 모니터링**
4. **손절매 기준 엄수**
5. **과도한 레버리지 금지**

### 법적 책임
- 모든 거래는 본인 책임입니다
- 시스템 오류로 인한 손실 책임 없음
- 투자는 신중하게 결정하세요
