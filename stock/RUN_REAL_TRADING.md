## 4️⃣ 실거래 시스템 동작 방식

### 매매 전략 (기본)

```rust
profit_target: 3.0,       // 3% 수익 시 매도
stop_loss: -2.0,          // -2% 손실 시 손절
max_position_ratio: 50.0, // 최대 50% 포지션
min_cash_ratio: 20.0,     // 최소 20% 현금 보유
```

### 자동 매수 조건

1. 기술적 분석 기반:
   - 상승 추세 (전일 대비 +0.5% 이상)
   - 장중 반등 (시가 대비 상승)
   - 낮은 변동성 (안정적 움직임)

2. 포지션 비율:
   - 종목당 최대 50% 포지션
   - 현금 비율 20% 이상 유지

3. 가격순 정렬:
   - 저렴한 종목부터 매수

### 자동 매도 조건

1. **목표 수익률**: 3% 이상 수익 시 자동 매도
2. **손절매**: -2% 이하 손실 시 자동 매도
3. **당일 매매 가능**: T+0 거래 (매수 즉시 매도 가능)

---

## 5️⃣ 안전 장치

### 자동 안전 체크

1. **보수적 계산**: 실제 매수가능 금액의 50-95%만 사용
2. **안전 마진**: 수수료 + 추가 비용 고려 (20% 여유)
3. **포지션 제한**: 종목당 최대 비율 제한
4. **현금 보유**: 최소 현금 비율 유지

### 수수료 구조

- 매수 수수료: 0.015%
- 매도 수수료: 0.015%
- 거래세: 0.25% (매도 시)

**예시**: 10만원 매수 → 수수료 1,500원, 총 필요 금액 101,500원

## 8️⃣ 일반적인 문제 해결

### 문제: "매수 수량이 0입니다"

**원인**: 
- 보유 현금 부족
- 주가가 너무 높음

**해결**:
- 계좌에 입금
- 저가 종목 추가

### 문제: "보유 현금 부족"

**원인**:
- 수수료와 안전 마진 미고려

**해결**:
- 충분한 현금 확보 (기본 필요 금액의 120%)
- 포지션 비율 조정

### 문제: "주문 거부"

**원인**:
- 거래 시간 외
- 종목 코드 오류
- 거래 정지

**해결**:
- 장 운영 시간 (09:00-15:30) 확인
- 종목 코드 재확인
